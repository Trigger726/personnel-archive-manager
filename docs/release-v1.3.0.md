# 人事档案管理 v1.3.0

下载 Windows 便携 ZIP，完整解压后运行 ArchiveManager.exe。需要 .NET Framework 4.8 或更高版本。

- 选择文件夹后，软件根据文件名识别资料关键词并展示匹配数量、示例及来源路径。可打开每组的文件核对列表。
- 识别建议保留作废、补充和附件等限定词，正确处理 v1.2 等版本标记。
- 支持取消扫描、查看上次结果、重新添加忽略项，以及查看未识别文件和读取问题。确认加入的关键词可用于资料筛选和按清单收集。
- 保存后重新加载、搜索、跨目录勾选、复制失败重试及源文件哈希回归已通过。19 个文件名用例有 17 个符合预期。仅含姓名的文件仍需人工核对，超长资料名可在未识别文件列表查看。真实共享盘未验收。
