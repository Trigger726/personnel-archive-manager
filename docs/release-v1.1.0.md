# 人事档案管理 1.1.0

解压后运行 `ArchiveManager.exe`。随包的 `Fonts` 目录提供应用所用的字体。

## 修复前后

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 清单页仅有「入职协议（补充说明）」 | 自动标为可收集 | 显示为候选，需人工确认 |
| 同时存在补充说明和「签署版_入职协议」 | 只显示补充说明并自动选中 | 两份都显示，需人工确认。候选表显示匹配依据、来源路径和修改时间 |
| 复制目标是档案库或员工目录 | 可以写入，刷新会重新索引副本 | 写入前拒绝该目标，并引导用户重新选择库外目录。也会解析通往档案库的本机目录联接 |
| 待复制源被移动、删除或无法读取 | 刷新后仍按正常条目显示，复制时才出现失败 | 刷新后标记，复制前再次检查。用户能定位或移除条目。确认框注明本次跳过的数量，其他文件可以继续复制 |

自动选择仅用于单个符合标准命名的候选。标准命名允许资料名后跟员工目录名、日期或两者。前缀说明、额外后缀和有多个匹配项的情况交由用户核对。档案副本仍沿用部门、员工和原文件名的命名规则。

## 验证范围

- 34 项现有回归及 15 项发布专项检查通过。覆盖重名、同名员工、跨目录勾选、拖入去重、库内导出拒绝、访问拒绝与恢复、复制部分失败及只重试失败项。核对了测试档案库原件的 SHA-256，复制输出与源内容匹配。
- 新版在 Windows 桌面成功启动，加载 81 份测试档案，搜索「入职协议」返回 15 份。桌面自动化无法定位对话框按钮，本次未完成候选核对、目标选择器、实际拖拽及两个动画的桌面验收。
- 本机用 20,000 个合成文件扫描约 153 毫秒。筛选并排序 10,000 个结果的七次中位数约 124 毫秒，未计 WPF 渲染。真实共享盘未接入，仅验证了 UNC 路径比较和本机目录联接。索引和线程模型沿用当前实现，待真实环境测量后决定优化方式。

## 开源参考

- Double Commander 会显示当前文件和整批进度，并支持取消。下一版可先为大文件和慢盘补上文件名、字节进度及取消，本版优先验证复制边界。 [复制操作文档](https://doublecmd.github.io/doc/en/copymove.html)
- Files 提供按需预览。后续适合把预览集中在候选核对页，帮助区分不同版本。本版继续使用候选页的「打开文件」。 [Files 操作文档](https://files.community/docs/features/command-palette)
- Paperless-ngx 可以保存常用筛选视图。后续适合把反复使用的资料组合做成收集模板，减少重复设置。 [Paperless-ngx 使用文档](https://github.com/paperless-ngx/paperless-ngx/blob/dev/docs/usage.md)
