# 人事档案管理

一款面向 HR 和行政人员的 **Windows 本地提效工具**。适合批量收集入职协议、劳动合同等材料，以及在归档前核对员工缺件。选定一批员工和所需资料后，工具会逐人核对，再将确认好的文件集中复制到指定目录。

## 能做什么

- **资料关键词管理**：从指定目录及子目录的文件名识别关键词，也可手动添加。支持取消扫描、查看上次结果和核对每组匹配文件。

- **按清单收集**：按员工和资料生成核对结果，区分「可收集」「待确认」和「未找到」。
- **核对候选文件**：有多个版本或文件名不规范时，可查看匹配依据、来源和修改时间，打开原文件后手动确认。
- **跟进缺件**：只看待处理项，或将未找到的条目复制到 Excel。
- **搜索和批量复制**：按文件名、路径、部门、员工、格式和资料关键词查找。切换目录或搜索条件后仍保留勾选，复制遇到同名文件时自动编号。

档案由程序在本机读取、匹配和复制，原档案保持原样。程序按文件名匹配资料，文件内容和有效性由使用者核对。

## 下载与使用

1. 从 [Releases](https://github.com/Trigger726/personnel-archive-manager/releases/latest) 下载 Windows 便携 ZIP，完整解压后双击 `ArchiveManager.exe`。需要 .NET Framework 4.8 或更高版本，字体随包提供。
2. 在「设置」里选择档案根目录。默认目录结构是「部门 → 员工文件夹 → 档案」，可调整部门和员工所在层级。
3. 点击「按清单收集」，勾选员工和资料。核对结果后点击「加入待复制」，再选择档案库之外的目标目录。

例如，要收集一个部门所有员工的劳动合同和入职协议，可以一次选择该部门的员工和这两种资料，核对待确认项后统一复制。

## 1.3.0

打开「资料关键词 → 管理资料关键词 → 指定文件夹识别」，选择要扫描的目录。软件根据文件名汇总资料关键词，可查看匹配文件及来源路径。确认加入后，新关键词可用于筛选和按清单收集。详见[发布说明](docs/release-v1.3.0.md)。

## 1.1.0

目录树支持拖拽加入待复制和展开动效。收集清单会列出全部候选，复制目标限定在档案库之外，待复制清单会标记找不到或无法读取的源文件。详见[发布说明](docs/release-v1.1.0.md)。

## 从源码构建

在装有 .NET Framework 4.8 的 Windows 上运行 `./src/Build.ps1`。如需重新打包，请先把便携包内的 `Fonts` 文件夹复制到 `src/Fonts`，再运行 `./src/Package.ps1 -OutputZip ./PersonnelArchiveManager-windows.zip`。
