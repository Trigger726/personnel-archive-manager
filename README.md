# 人事档案管理

一款面向 HR 和行政人员的 **Windows 本地提效工具**。适合批量收集入职协议、劳动合同等材料，以及在归档前核对员工缺件。选定一批员工和所需资料后，工具会逐人核对，再将确认好的文件集中复制到指定目录。

## 能做什么

- **按清单收集**：按员工和资料生成核对结果，区分「可收集」「待确认」和「未找到」。
- **核对候选文件**：有多个版本或文件名不规范时，可查看来源和修改时间，打开原文件后手动确认。
- **跟进缺件**：只看待处理项，或将未找到的条目复制到 Excel。
- **搜索和批量复制**：按文件名、路径、部门、员工、格式和资料关键词查找。切换目录或搜索条件后仍保留勾选，复制遇到同名文件时自动编号。

档案由程序在本机读取、匹配和复制，原档案保持原样。程序按文件名匹配资料，文件内容和有效性由使用者核对。

## 下载与使用

1. 从 [Releases](https://github.com/Trigger726/personnel-archive-manager/releases/latest) 下载 Windows 便携 ZIP，完整解压后双击 `ArchiveManager.exe`。需要 .NET Framework 4.8 或更高版本，字体随包提供。
2. 在「设置」里选择档案根目录。默认目录结构是「部门 → 员工文件夹 → 档案」，可调整部门和员工所在层级。
3. 点击「按清单收集」，勾选员工和资料。核对结果后点击「加入待复制」，再选择目标目录。

例如，要收集一个部门所有员工的劳动合同和入职协议，可以一次选择该部门的员工和这两种资料，核对待确认项后统一复制。
